ℹ️ Information

Bienvenue sur l'interface du Moteur Morphologique Arabe.
Cette application permet de :

  • 📚 Charger et afficher les racines arabes
  • 🔄 Générer les dérivés morphologiques
  • ✅ Valider des mots contre des racines
  • 📐 Gérer les schèmes morphologiques
  • 🔍 Identifier les racines d'un mot
✨ Note : Pour utiliser pleinement l'application, assurez-vous que les fichiers racines.txt et schemes.txt sont présents dans le même répertoire que l'exécutable.
